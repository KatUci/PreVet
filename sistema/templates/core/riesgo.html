¿Cómo se calcula el riesgo?

Cada cita recibe un puntaje de 0 a 100 que suma cuatro factores, según su peso:

{% for nombre, peso in pesos %}
{{ nombre }}{{ peso }}

  • ≥{{ umbral_alto }} Alto: {{ acciones.alto }}.
  • ≥{{ umbral_medio }} Medio: {{ acciones.medio }}.
  • <{{ umbral_medio }} Bajo: {{ acciones.bajo }}.

Si el tutor viene por primera vez, su historial cuenta con un valor neutro.

Con el nivel también cambia el contacto: a riesgo alto el WhatsApp pide responder "SÍ" para confirmar; a riesgo medio, recuerda la hora y ofrece cambiarla; a riesgo bajo, es un aviso breve. "Qué decir" arma un guion de llamada con los factores de cada cita.
