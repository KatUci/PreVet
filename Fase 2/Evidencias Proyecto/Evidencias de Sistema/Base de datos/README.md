# Base de datos

- `PreVet_Script_BaseDatos.sql`: script con las tablas, índices, grupos de usuarios (Administración, Recepción, Veterinarios) con sus permisos, y los catálogos de especies y razas. Se generó desde las migraciones de Django y se probó sobre una base vacía. No incluye cuentas ni contraseñas.
- `PreVet_MER.png` / `PreVet_MER.pdf`: modelo entidad-relación con las 12 tablas del sistema, sus llaves primarias y foráneas y la cardinalidad de cada relación.
